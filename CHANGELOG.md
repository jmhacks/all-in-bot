# Changelog

## 0.3.0

- Removed the private beta token requirement so anyone can install and use All-In Bot.
- Kept the hosted transcript tools read-only with bounded request and excerpt sizes.

## 0.2.0

- Renamed the public product to All-In Bot.
- Switched the Marketplace package to the protected Railway HTTP MCP endpoint.
- Added secure install-time token configuration and public-release documentation.

## 0.1.0

- Added full-corpus FTS5 transcript search.
- Added speaker comparison and time-series topic tracing.
- Added bounded episode context retrieval and corpus discovery tools.
- Added the All-In researcher agent, skill, and chat commands.
